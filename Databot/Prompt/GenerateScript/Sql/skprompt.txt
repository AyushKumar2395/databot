CRITICAL: DB_NAME() PROHIBITION (READ THIS FIRST)
========================================================
NEVER write:  DB_NAME() AS [DatabaseName]
WHY: DB_NAME() returns the CURRENT CONNECTION database (always "master").
     When iterating sys.databases rows it produces the same wrong value on every row.

CORRECT PATTERN for listing databases:
  SELECT @@SERVERNAME AS [ServerName], d.name AS [DatabaseName], GETDATE() AS [CapturedAt]
  FROM sys.databases d
  ORDER BY d.name

DB_NAME() is ONLY allowed as [ContextDatabase] in queries that run within a specific database.

========================================================
DOMAIN PLAYBOOK — CANONICAL SOURCES
========================================================
Use the most authoritative source for each domain. Do NOT improvise alternative views when the canonical one exists.

A. INSTANCE / SERVER INFO
   Canonical: sys.configurations, sys.dm_os_sys_info, SERVERPROPERTY()
   - Edition, version, collation: SELECT SERVERPROPERTY('Edition'), SERVERPROPERTY('ProductVersion')
   - Max memory: SELECT value_in_use FROM sys.configurations WHERE name = 'max server memory (MB)'
   - CPU count: SELECT cpu_count, hyperthread_ratio FROM sys.dm_os_sys_info
   - Uptime: SELECT sqlserver_start_time FROM sys.dm_os_sys_info

B. DATABASE LIST / STATUS
   Canonical: sys.databases (alias: d)
   - Use d.name AS [DatabaseName] — NOT DB_NAME()
   - State: d.state_desc AS [State]
   - Recovery model: d.recovery_model_desc AS [RecoveryModel]
   - Compatibility: d.compatibility_level AS [CompatLevel]
   - Owner: SUSER_SNAME(d.owner_sid) AS [Owner]

C. DATABASE SIZE
   Canonical: sys.master_files (alias: mf) joined to sys.databases (alias: d)
   SELECT
       d.name AS [DatabaseName],
       SUM(CASE WHEN mf.type = 0 THEN mf.size END) * 8.0 / 1024 AS [DataSizeMB],
       SUM(CASE WHEN mf.type = 1 THEN mf.size END) * 8.0 / 1024 AS [LogSizeMB]
   FROM sys.master_files mf
   JOIN sys.databases d ON d.database_id = mf.database_id
   GROUP BY d.name

D. BACKUP HISTORY
   Canonical: msdb.dbo.backupset (alias: bs) + msdb.dbo.backupmediafamily (alias: bmf)
   CRITICAL: Always guard msdb access:
     IF DB_ID('msdb') IS NOT NULL AND OBJECT_ID('msdb.dbo.backupset') IS NOT NULL BEGIN ... END
   Key columns:
     bs.database_name, bs.backup_start_date, bs.backup_finish_date,
     bs.backup_size / 1048576.0 AS [BackupSizeMB],
     bs.type (D=Full, I=Differential, L=Log),
     bmf.physical_device_name AS [BackupFile]
   Most recent per database:
     Use ROW_NUMBER() OVER (PARTITION BY bs.database_name ORDER BY bs.backup_finish_date DESC)

E. SQL AGENT JOBS
   Canonical: msdb.dbo.sysjobs (sj), msdb.dbo.sysjobhistory (h), msdb.dbo.sysjobsteps (js)
   CRITICAL GOTCHAS — READ CAREFULLY:
     - h.run_date is INT stored as yyyymmdd (e.g. 20260304). It is NOT a date/datetime column.
     - h.run_time is INT stored as hhmmss (e.g. 143000 = 14:30:00). It is NOT a time column.
     - NEVER do: WHERE h.run_date >= GETDATE()  ← This causes Msg 206 Operand type clash
     - NEVER do: CAST(h.run_time AS time)        ← This causes Msg 245 Conversion failed
     - To get a real datetime: msdb.dbo.agent_datetime(h.run_date, h.run_time) AS [RunDateTime]
     - To filter by date range using INT columns:
         DECLARE @DateInt int = CONVERT(int, CONVERT(char(8), GETDATE()-7, 112));
         WHERE h.run_date >= @DateInt
     - h.run_status: 0=Failed, 1=Succeeded, 2=Retry, 3=Cancelled, 4=In progress
     - h.step_id = 0 is the job-level outcome row (not a step row)
   ALWAYS guard: IF DB_ID('msdb') IS NOT NULL AND OBJECT_ID('msdb.dbo.sysjobs') IS NOT NULL BEGIN ... END

F. BLOCKING / WAIT INFO
   Canonical: sys.dm_exec_requests (r), sys.dm_exec_sessions (s), sys.dm_os_waiting_tasks (wt)
   - Blocking: r.blocking_session_id > 0
   - Query text: CROSS APPLY sys.dm_exec_sql_text(r.sql_handle) AS st
   - Wait type: r.wait_type, r.wait_time / 1000.0 AS [WaitSec]
   - Input buffer: CROSS APPLY sys.dm_exec_input_buffer(s.session_id, r.request_id)

G. WAIT STATISTICS
   Canonical: sys.dm_os_wait_stats
   - Exclude benign waits: WHERE wait_type NOT IN ('SLEEP_TASK','LAZYWRITER_SLEEP','BROKER_TO_FLUSH',
     'SQLTRACE_BUFFER_FLUSH','CLR_AUTO_EVENT','DISPATCHER_QUEUE_SEMAPHORE',
     'XE_DISPATCHER_WAIT','XE_TIMER_EVENT','WAITFOR','REQUEST_FOR_DEADLOCK_SEARCH',
     'LOGMGR_QUEUE','CHECKPOINT_QUEUE','DBMIRROR_EVENTS_QUEUE','FT_IFTS_SCHEDULER_IDLE_WAIT')
   - Order by: waiting_tasks_count DESC or wait_time_ms DESC

H. MEMORY
   Canonical: sys.dm_os_memory_clerks, sys.dm_os_process_memory, sys.dm_os_performance_counters
   - Buffer pool: SELECT pages_kb/1024.0 AS [MemMB] FROM sys.dm_os_memory_clerks WHERE type='MEMORYCLERK_SQLBUFFERPOOL'
   - Total target: SELECT cntr_value/1024 AS [TargetMB] FROM sys.dm_os_performance_counters
     WHERE counter_name='Target Server Memory (KB)' AND object_name LIKE '%Memory Manager%'

I. LOG SPACE
   Canonical: sys.dm_db_log_space_usage (per database), DBCC SQLPERF(LOGSPACE) (all DBs)
   - Per-DB log used %: SELECT log_space_used_mb, log_space_used_percent FROM sys.dm_db_log_space_usage
   - Note: sys.dm_db_log_space_usage is scoped to current DB; for all DBs use sp_MSforeachdb or DBCC SQLPERF

J. ALWAYS ON / AVAILABILITY GROUPS
   Canonical: sys.availability_groups (ag), sys.availability_replicas (ar),
              sys.dm_hadr_availability_replica_states (rs), sys.dm_hadr_database_replica_states (drs)
   - Sync state: rs.synchronization_health_desc, rs.connected_state_desc
   - Redo queue: drs.redo_queue_size, drs.log_send_queue_size

K. ERROR LOG
   Canonical: sys.xp_readerrorlog (via EXEC xp_readerrorlog)
   Signature: xp_readerrorlog [LogNumber], [LogType], [SearchText1], [SearchText2], [StartDate], [EndDate], [SortOrder]
   Example:   EXEC xp_readerrorlog 0, 1, N'error', NULL, NULL, NULL, N'desc'

L. SECURITY / LOGINS / PERMISSIONS
   Canonical: sys.server_principals (sp), sys.database_principals (dp),
              sys.server_role_members, sys.database_role_members,
              sys.database_permissions, fn_my_permissions()
   - Sysadmins: SELECT sp.name FROM sys.server_principals sp
     JOIN sys.server_role_members rm ON rm.member_principal_id = sp.principal_id
     JOIN sys.server_principals r ON r.principal_id = rm.role_principal_id AND r.name = 'sysadmin'

M. SCHEMAS / INDEXES / OBJECTS
   Canonical: sys.tables (t), sys.indexes (i), sys.columns (c), sys.schemas (s),
              sys.dm_db_index_usage_stats (ius), sys.dm_db_index_physical_stats()
   - Index fragmentation: sys.dm_db_index_physical_stats(DB_ID(), NULL, NULL, NULL, 'LIMITED')
   - Missing indexes: sys.dm_db_missing_index_details, sys.dm_db_missing_index_groups, sys.dm_db_missing_index_group_stats

N. TRIGGERS
   Canonical: sys.triggers (tr), sys.sql_modules (sm), OBJECT_DEFINITION()
   - All triggers: SELECT tr.name, OBJECT_NAME(tr.parent_id) AS [TableName], tr.is_disabled
     FROM sys.triggers tr WHERE tr.parent_class = 1

O. IN-MEMORY OLTP (HEKATON)
   Canonical: sys.tables WHERE is_memory_optimized = 1
              sys.dm_db_xtp_memory_consumers, sys.dm_xtp_transaction_stats

P. PERFORMANCE / TOP QUERIES
   Canonical: sys.dm_exec_query_stats (qs), sys.dm_exec_cached_plans (cp)
   - CROSS APPLY sys.dm_exec_sql_text(qs.sql_handle) AS st
   - CROSS APPLY sys.dm_exec_query_plan(qs.plan_handle) AS qp
   - Sort by: total_worker_time, total_elapsed_time, total_logical_reads, execution_count
